# Quiz
test-quiz-repo. Цей репозиторій містить вихідний код та ресурси мобільного застосунку Quiz, розробленого в середовищі Android Studio в межах виконання практичних завдань із дисципліни. Додаток реалізує інтерактивну вікторину з підтримкою динамічного керування інтерфейсом, локалізації ресурсів та базовою логікою підрахунку результатів.
